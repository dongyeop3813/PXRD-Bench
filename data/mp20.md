# MP-20 input assets

Place the prepared MP-20 assets under `data/mp20`, or override
`data.data_root` in training and evaluation.

The training and evaluation commands load these assets; dataset preprocessing
and split generation are not included in this repository.

| Path | Used by |
| --- | --- |
| `raw/train.csv`, `raw/val.csv`, `raw/test.csv` | The supplied MP-20 split definitions. |
| `processed/mp20_tokens_{split}.pt` | Known-stoichiometry training and evaluation references. |
| `processed/mp20_tokens_{split}_order_mcflow_v1_symprec0p1.pt` | Element-set training and validation, with MCFlow ordering metadata. |
| `pxrd_peaks/bragg-v2_{split}_wl1.54184_tt5-90_src{digest}.pt` | Bragg reflections matching the exact token cache and its ID order. |
| `pxrd_peaks/xrdiff_peaks_128x4_k512_wl1.54184_tt5-90_src{digest}_{split}.pt` | Deterministic training-reference, validation and evaluation peak features. |
| `structure_cache/primitive_niggli_v1/mp20_tokens.{split}.lmdb/` | Canonical structure caches for the known-stoichiometry preset. |

Provide the train/validation files for training, and the requested split for
evaluation. Element-set training requires its own matching Bragg and deterministic
feature caches: reordering atoms changes the token-source fingerprint.
Keep the ordinary token caches and their corresponding PXRD caches for evaluation
references. Do not rename a cache from another token ordering to satisfy a path;
the loader checks source fingerprints and ordered IDs.

Additional representations using stored dense PXRD require `pxrd/{split}.pt`.
The default presets use the reflection and peak-feature caches listed above.
